# Reference resources

Curated lists to check before building something from scratch, hunting for a paid
service, or reaching for a random scraper/MCP implementation:

- **Free-for-dev** — https://github.com/jixserver/free-for-dev
  Free tiers of cloud, dev-tool, and infra services. Check here before assuming
  something needs a paid plan (hosting, DBs, email, monitoring, CI, etc.).
- **Public APIs** — https://github.com/public-apis/public-apis
  Large categorized directory of free public APIs. Check here before scraping
  or building a data source from scratch.
- **Scrapling** — https://github.com/d4vinci/Scrapling
  Python web scraping library (adaptive selectors, stealth/anti-bot fetching).
  Prefer this over hand-rolled requests/BeautifulSoup scrapers when a target
  site pushes back on naive scraping.
- **Awesome MCP servers** — https://github.com/punkpeye/awesome-mcp-servers
  Curated list of MCP servers. Check here before writing a new MCP server from
  scratch — one may already exist for the target service.
